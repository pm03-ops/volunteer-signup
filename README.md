# 志工服務報名系統

單檔網頁應用（`index.html`），給機構志工報名每週／單次活動用。

- 線上網址：https://pm03-ops.github.io/volunteer-signup/
- 資料庫：Supabase（`volunteer_config` ＋ `volunteer_signups` 兩張表），建表 SQL 在 `schema.sql`
- 未連上雲端時自動退回瀏覽器 localStorage 模式，連上後多裝置即時同步

## 功能

- 選頭像報名（免登入）、時段選擇、每時段人數上限（額滿顯示、取消自動釋出名額）
- 每人每月 2 場名額；活動可設「一場抵 2 場」；超額時跳窗二選一改報
- 個人頁月曆：綠色＝已報名（滑鼠懸停看內容）、點日期篩選活動
- 後台：勾週幾＋期間建立每週系列、人數上限／名額計算設定、總覽（凍結姓名與統計欄）、報表、出席登記
- 匯出／匯入 JSON 備份

## 注意

- anon key 內建於前端，等同「知道網址的人都能讀寫」，**請勿輸入住民姓名、床號、病歷號**。
- 極端情況（兩人同一秒搶最後一個名額）可能超收 1 名；資料庫會擋「同一人同一場報兩次」，超收可在總覽人工調整。

## 更新方式

改好 `index.html` 後，到 https://github.com/pm03-ops/volunteer-signup/upload/main 拖進去覆蓋即可。
